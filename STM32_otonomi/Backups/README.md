# STM32 kart yedekleri

Bu klasördeki `.bin` dosyaları, yeni firmware yazılmadan önce bağlı karttan SWD ile alınan ham flash yedekleridir.

- Başlangıç adresi: `0x08000000`
- STM32L152RE flash boyutu: `0x80000` bayt / 512 KiB
- Kart: NUCLEO-L152RE

Bu dosyalar kaynak kod değildir; yalnız aynı MCU'ya geri yükleme/inceleme amacıyla saklanır.
